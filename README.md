# Digital Logic Labs

Two Logisim circuit designs demonstrating combinational and sequential digital logic.

## Circuits

### Combinational Logic

`combinational-logic.circ` uses AND, OR, NOT, and NOR gates with LED outputs. It demonstrates how larger Boolean functions can be assembled from elementary gates.

### Sequential Counter

`sequential-counter.circ` uses seven falling-edge-triggered J-K flip-flops, a clock, and supporting logic to demonstrate sequential state transitions and counting behaviour.

## Open the Files

The files were created with Logisim 2.7.2. Open either `.circ` file in Logisim or a compatible fork.
